# HOUSEHUB

Expense splitting, settlements and chores for shared houses — with XP, levels, achievements and a
leaderboard, so tidying up the kitchen is at least mildly competitive.

Built as a MERN application: React + Vite on the front, Express + MongoDB on the back, and one small
`shared/` module both halves import for the money and XP mathematics. The UI is its own design system
on top of Tailwind, with Radix primitives for dialogs, menus and tooltips, Framer Motion for
transitions, and Sonner for toasts.

Three decisions shape the whole codebase:

- **No drift between client and server.** The split a user previews in the expense form is literally
  the function the server runs, because both import `shared/money.js`.
- **Balances are derived, never stored.** Delete an expense and every balance is instantly correct.
- **The URL is never the authorisation.** Every house-scoped route proves membership before a
  controller runs, so swapping a house id returns `403`, not another house's data.

## Features

- **Accounts** — register, sign in, JWT sessions, profile editing, change password, forgot/reset
  password, delete account.
- **Houses** — create, join by invite link or code, members with roles, role changes, ownership
  transfer, member removal, leave (the house cleans itself up when the last member goes).
- **Expenses** — search, filter, sort and paginate. Split equally, by exact amounts, or by
  percentage, with a receipt URL and description.
- **Balances** — derived on read. Shows both your pairwise position ("you owe X, Y owes you") and the
  minimal set of payments that settles the whole house.
- **Settlements** — record a payment; it moves the ledger only once the receiver confirms it.
  Confirm, reject, remind, cancel.
- **Chores** — assignee, due date, priority and XP reward. Start, complete, edit, delete. Overdue is
  derived, never stored. "My Chores" buckets work into overdue / today / upcoming / completed.
- **Gamification** — XP credited exactly once per chore, a non-linear level curve, achievements that
  unlock from server-side counters, a dense-ranked leaderboard, and an activity feed.
- **Dashboard & analytics** — spend, what you owe, what you're owed, chores, top of the leaderboard
  and recent activity in one request; spend by month, category and member.
- **Notifications** — generated by house activity, with an unread count in the header.
- **Interface** — a Tailwind design system with semantic tokens, glass/gradient surfaces, real motion,
  and dark-first light/dark/system theming applied before first paint.

| Testing       | Vitest + Supertest against a real database, plus an end-to-end smoke runner                 |

## Quick start

**Prerequisites:** Node.js **18.17+** and MongoDB running locally (or an Atlas connection string).

```bash
# 1. Install everything (root, server and client, via the postinstall hook)
npm install

# 2. Configure the API
cp server/.env.example server/.env
#    then set a real JWT_SECRET. Generate one with:
#    node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

# 3. Start MongoDB if it is not already running
mongod --dbpath /path/to/data

# 4. Optional: load the demo house
npm run seed

# 5. Run the API and the web app together
npm run dev
```

The API runs on `http://localhost:5000` and the web app on `http://localhost:5173`. Register from the
app, or sign in as a demo user below.

The client needs no `.env` locally: `client/vite.config.js` proxies `/api` to `localhost:5000`, so
there is no absolute URL to keep in sync and no CORS preflight during development.

## Roles and permissions

A member's role lives on `House.members[].role`. `houseScope` always proves membership; role guards
gate privileged actions.

| Action                                            | Member | Admin | Owner |
| ------------------------------------------------- | :----: | :---: | :---: |
| View dashboard, balances, analytics, activity     |   ✅   |  ✅   |  ✅   |
| Create / edit / delete your own expense           |   ✅   |  ✅   |  ✅   |
| Edit / delete another member's expense            |   —    |  ✅   |  ✅   |
| Create a chore; start / complete your own chore   |   ✅   |  ✅   |  ✅   |
| Start / complete someone else's chore             |   —    |  ✅   |  ✅   |
| Request a settlement; confirm one sent to you     |   ✅   |  ✅   |  ✅   |
| Edit house settings, regenerate the invite code   |   —    |  ✅   |  ✅   |
| Remove another member                             |   —    |  ✅   |  ✅   |
| Change a member's role                            |   —    |   —   |  ✅   |
| Transfer ownership                                |   —    |   —   |  ✅   |
| Leave the house                                   |   ✅   |  ✅   |  ✅\* |

\* An owner with other members must transfer ownership before leaving; the last member out deletes the
house. Every rule here is exercised in `server/tests/security.test.js`.
